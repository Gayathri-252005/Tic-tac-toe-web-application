🎮 Tic-Tac-Toe Web Application

A responsive and interactive Tic-Tac-Toe Web Application built using HTML, CSS, and JavaScript. This project allows two players to compete in a classic Tic-Tac-Toe game with real-time winner detection, draw handling, and an attractive user interface.

📌 Project Overview

The Tic-Tac-Toe game is a simple yet engaging web application that demonstrates core JavaScript concepts such as DOM manipulation, event handling, game logic, and state management. Players take turns placing X and O on a 3×3 grid, aiming to align three markers horizontally, vertically, or diagonally to win.

✨ Features
🎯 Interactive 3×3 game board
👥 Two-player gameplay (Player X & Player O)
🏆 Automatic winner detection
🤝 Draw game detection
🔄 Reset/New Game functionality
📱 Responsive design for desktop and mobile devices
🎨 Clean and modern user interface
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and responsive design
JavaScript (ES6) – Game logic and interactivity

🎮 How to Play
Player X starts the game.
Players take turns clicking on empty cells.
The first player to place three marks in a row (horizontal, vertical, or diagonal) wins.
If all nine cells are filled without a winner, the game ends in a Draw.
Click the Reset or New Game button to play again.
